# list-comprehension-in-python
## About the Project

This project demonstrates the concept of List Comprehension in Python with simple examples. List comprehension is a short and easy way to create new lists from existing lists using a single line of code.

 ## Topics Covered

Basic List Comprehension

Doubling Numbers

Squaring Numbers using the Exponent Operator (**)

List Comprehension with range()

Filtering Even and Odd Numbers

Accessing String Characters using Indexing

String Slicing (start:stop:step)

Converting City Names into Uppercase

Converting Food Names into Lowercase

Using Conditional Statements (if)
